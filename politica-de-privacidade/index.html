Política de Privacidade

Última atualização: 22 de setembro de 2026

Esta política explica como o Fusion trata dados pessoais quando você usa o catálogo, cria uma conta ou marca jogos como favoritos.

Dados que tratamos

Quando você entra com o Google ou cria uma conta com e-mail, o Fusion recebe os dados necessários para identificar sua conta, como e-mail, nome exibido e identificador de usuário. Também armazenamos os jogos que você escolhe como favoritos.

Como usamos esses dados

Usamos esses dados para autenticar sua conta, manter sua lista de favoritos sincronizada e proteger o acesso à sua biblioteca. Não vendemos dados pessoais e não usamos seus dados para publicidade comportamental.

Serviços que ajudam o Fusion a funcionar

O login e os dados de conta são processados pelo Supabase. Quando você escolhe entrar com o Google, a autenticação é realizada pelo Google. As informações públicas dos jogos vêm da Steam. Cada serviço pode tratar dados de acordo com suas próprias políticas de privacidade.

Compartilhamento e segurança

Compartilhamos apenas o necessário com os provedores acima para operar o serviço. A lista de favoritos é protegida por conta: uma pessoa autenticada não pode consultar nem alterar a lista de outra pessoa.

Retenção e seus controles

Os dados de conta e favoritos são mantidos enquanto sua conta estiver ativa ou enquanto forem necessários para oferecer o serviço. Você pode remover favoritos a qualquer momento. Para solicitar acesso, correção ou exclusão de dados, use o canal de suporte disponibilizado no aplicativo.

Atualizações desta política

Podemos atualizar esta política para refletir melhorias no Fusion ou exigências legais. A data no topo indica a versão em vigor.
